Meridian Protocol Custom Audio Resource Pack
Minecraft Java 1.21.1

Installation:
1. Put this ZIP in the resourcepacks folder for each player who needs to hear the custom sounds.
2. Enable the pack in Options > Resource Packs.
3. Run /reload in-game after enabling it.

Registered sound events:
- meridian:chase_music
- meridian:heartbeat
- meridian:humming_lights_with_flicker
- meridian:metal_creaking
- meridian:monster_roar
- meridian:monster_eating
- meridian:monster_growl1
- meridian:monster_growl2
- meridian:monster_step_left
- meridian:monster_step_right
- meridian:monster_step_with_growl
- meridian:monster_step
- meridian:suspense_sound
- meridian:suspense_sound2

Example:
 /playsound meridian:chase_music master @a ~ ~ ~ 1 1

The chase music event is marked as streamed because it is a longer audio track.
